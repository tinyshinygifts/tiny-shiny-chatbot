v39 update (base v38):

1. Bandwidth Saver Mode added.
   - Admin Panel → API Settings → Bandwidth Saver Mode
   - ON/OFF switch
   - Shopify cache TTL
   - Meta Ads cache TTL
   - Admin auto-refresh seconds
   - Google Sheet auto-save control while saver is ON
   - Clear API Cache button

2. Shopify API bandwidth reduction.
   - Shopify Products API now uses cache when saver is ON.
   - Shopify Customers + latest order enrichment now uses cache when saver is ON.
   - Default saver cache: 21600 seconds (6 hours).
   - API response shows cached/cacheAgeSec/bandwidthSaver.

3. Meta Ads report bandwidth reduction.
   - Meta Ads insights now uses cache when saver is ON.
   - Default saver cache: 1800 seconds (30 minutes).

4. Google Sheets bandwidth reduction.
   - When Bandwidth Saver is ON, auto-save to Google Sheets is disabled by default.
   - It can be re-enabled using "Saver ON me Google Sheet auto-save allow".

5. Broadcast scheduler bandwidth reduction.
   - Due broadcast scheduler interval changes from 30 seconds to 5 minutes while saver is ON.

6. Admin auto-refresh reduction.
   - When saver is ON, auto-refresh only refreshes the active tab.
   - It avoids broad polling of leads/events/messages on every interval.
   - Recommended interval: 600 seconds.

7. External API call logging added.
   - Recent Shopify/Meta outbound calls are logged in Bandwidth Settings status for debugging.
   - Helps identify which module is using service-initiated bandwidth.

8. Previous fixes preserved from v38:
   - Real OpenAI API for Meta Ads AI
   - Real Meta campaign/adset/ad creation in PAUSED status
   - Meta Ads reporting
   - Safe bulk broadcast with opt-in and random delay
   - Meta WhatsApp Template Creator
   - Cloudinary uploads
   - CRM Pending Approval tab
